🛡 MÜDAFİƏ STRATEGİYALARI

DNS hücumlarına qarşı sənaye standartı müdafiə texnikaları.

🔐
DNSSEC
Kriptoqrafik imzalarla DNS cavablarının autentifikasiyası. Cache Poisoning-ə qarşı ən effektiv müdafiə. RRSIG, NSEC, DS qeydlərindən istifadə edir.
dnssec-keygen -a RSASHA256 -b 2048 -n ZONE example.az
dnssec-signzone -A -3 $(head -c 1000 /dev/random | sha1sum | cut -b 1-16) example.az
📊
Rate Limiting (RRL)
BIND Response Rate Limiting — eyni IP-dən gələn həddindən artıq sorğuları məhdudlaşdırır. Amplification hücumlarına qarşı effektivdir.
rate-limit {
  responses-per-second 10;
  errors-per-second 5;
  nxdomains-per-second 5;
  slip 2;
};
🔥
DNS Firewall (RPZ)
Response Policy Zone — zərərli domainlərə giriş bloklama. ISP-lər tərəfindən geniş istifadə olunur.
response-policy {
  zone "rpz.blocklist";
};
; zone file:
malware.example.com CNAME .
*.malware.example.com CNAME .
🌐
BCP38 Anti-Spoofing
ISP səviyyəsinde IP spoofing-in qarşısının alınması. Amplification hücumlarının kökündə dayanan problemi həll edir.
# Cisco IOS
ip verify unicast source reachable-via rx
# iptables
-A PREROUTING -m rpfilter --invert -j DROP
